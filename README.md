# Планировщик: сборка APK без Android Studio

1. Зарегистрируйтесь на github.com (бесплатно) и создайте новый репозиторий (New repository, можно Private).
2. На странице репозитория нажмите «uploading an existing file» и перетащите ВСЁ содержимое этой папки (включая скрытую папку .github). Нажмите Commit changes.
3. Откройте вкладку Actions → «Build APK». Сборка идёт 5–10 минут, в конце появится зелёная галочка.
4. Откройте завершённый запуск, внизу в разделе Artifacts скачайте planner-apk (внутри файл app-debug.apk).
5. Перенесите app-debug.apk на телефон, откройте его и разрешите установку из неизвестных источников.

Приложение работает полностью офлайн, данные хранятся на телефоне.
